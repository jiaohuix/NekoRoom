# Security Policy

NekoRoom is an early-stage project and its security processes are still being established.

## Reporting a vulnerability

Please **do not** publish sensitive vulnerability details, credentials, tokens, private endpoints, or exploit material in a public issue.

Preferred reporting path:

1. Use GitHub's private vulnerability reporting for `NekoAI-Labs/NekoRoom` if it is enabled.
2. If private vulnerability reporting is not available, contact the maintainers through an official NekoAI-Labs contact channel before disclosing details publicly.

When reporting, include the affected version or commit, platform, reproduction steps, impact, and any known mitigation.

## Secrets

If you discover a credential or secret committed to the repository, treat it as compromised even if it is later removed from the current branch. Notify maintainers privately so the credential can be rotated and Git history can be reviewed.
